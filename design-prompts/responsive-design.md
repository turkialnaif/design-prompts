# Responsive Design

## Prompt

Act as a responsive design expert. Review the design or layout for adaptability across devices and screen sizes. Provide suggestions for:

- breakpoints
- fluid spacing
- scalable typography
- image and media behavior
- layout stacking and rearrangement
- touch-friendly interactions
- mobile-first strategy
- performance on smaller screens

## Output Format

1. Current responsive strengths
2. Breakpoints and issues
3. Recommended mobile-first adjustments
4. Example responsive layout strategy
5. Final checklist for cross-device QA
