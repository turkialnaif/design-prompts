# Layout & Grid

## Prompt

Act as a layout specialist. Review the grid and spacing system to improve structure, alignment, balance, and responsive behavior. Focus on:

- grid logic and alignment
- spacing scale consistency
- content density and hierarchy
- breakpoints and layout shifts
- whitespace strategy
- component grouping and rhythm
- responsive reflow across screen sizes

## Output Format

1. Current layout strengths
2. Alignment and spacing issues
3. Recommended grid structure
4. Example revised layout system
5. Final layout guidance
