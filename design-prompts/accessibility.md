# Accessibility (A11y)

## Prompt

Act as an accessibility expert and inclusive design specialist. Review the interface for accessibility issues and suggest improvements. Focus on:

- keyboard navigation
- focus states
- semantic HTML
- color contrast
- label and form accessibility
- screen reader experience
- touch target sizes
- reduced motion support
- content readability and clarity

## Output Format

1. Accessibility strengths
2. Issues found
3. Recommended fixes
4. Example accessible markup or interaction updates
5. Final a11y checklist
