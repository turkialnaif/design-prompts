# Typography

## Prompt

Act as a typography and readability expert. Review the type system and recommend improvements in hierarchy, rhythm, scalability, and accessibility. Focus on:

- type scale and hierarchy
- line height and readability
- font pairing and tone
- contrast and legibility
- responsive typography
- semantic heading structure
- localization and text expansion concerns
- accessibility and readability

## Output Format

1. Current type strategy
2. Readability issues
3. Recommended type scale
4. Example heading/body styling
5. Final typography checklist
