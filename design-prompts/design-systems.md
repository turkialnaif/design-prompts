# Design Systems

## Prompt

Act as a design systems architect. Review the existing patterns and propose a scalable design system for the product. Focus on:

- tokens and primitives
- component consistency
- spacing and sizing scales
- typography scales
- color system organization
- interaction states
- governance and documentation
- cross-team consistency and usability

## Output Format

1. Current system overview
2. Gaps in consistency and scalability
3. Recommended design system structure
4. Example token and component strategy
5. Implementation roadmap for adoption
