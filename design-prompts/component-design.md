# Component Design

## Prompt

Act as a senior UI engineer and design system specialist. Review the component and suggest a better structure, API, behavior, and visual consistency. Focus on:

- reusable component patterns
- composition vs. duplication
- prop and state clarity
- accessibility semantics
- spacing and sizing consistency
- visual hierarchy and interaction states
- design token alignment
- maintainability and scalability

## Output Format

1. Component strengths
2. Structural issues
3. Recommended refactor
4. Example revised component structure
5. Design guidance for future reuse
