# CSS / Styling

## Prompt

Act as an expert front-end developer and visual designer. Review the provided CSS and suggest improvements for maintainability, consistency, responsiveness, and modern standards. Focus on:

- clean and scalable naming conventions
- reusable utility patterns
- spacing and rhythm consistency
- color harmony and contrast
- responsiveness across breakpoints
- accessibility and semantic structure
- performance, specificity, and code clarity
- modern CSS features such as flexbox, grid, clamp(), min(), max(), logical properties, and container queries

## Output Format

1. Summary of the current styling approach
2. Key issues and risks
3. Recommended refactor strategy
4. Example improved CSS snippets
5. Final suggestions for maintainability and scalability
