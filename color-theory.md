# Color Theory

## Prompt

Act as a color design expert. Evaluate the palette and suggest improvements for harmony, accessibility, hierarchy, and branding. Focus on:

- color balance and contrast
- primary, secondary, and accent roles
- color meaning and emotional tone
- accessibility and WCAG contrast compliance
- consistency across components and states
- accessibility for color-blind users
- systematization through tokens

## Output Format

1. Current palette overview
2. Strengths and issues
3. Recommended palette adjustments
4. Contrast analysis
5. Suggested design token structure
