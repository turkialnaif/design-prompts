# UI/UX Design

## Prompt

Act as a senior product designer and UX strategist. Evaluate the interface and improve usability, clarity, interaction design, and visual hierarchy. Focus on:

- user goals and flows
- information hierarchy
- consistency and alignment
- visual balance
- call-to-action clarity
- friction reduction
- mobile-first optimization
- accessibility and inclusive design

## Output Format

1. UX strengths
2. UX pain points
3. Recommended improvements
4. Suggested UI hierarchy
5. Example revised layout concept
