# CSS / Styling

## Prompt

Act as an expert front-end developer and visual designer. Review the provided CSS and suggest improvements for maintainability, consistency, responsiveness, and modern best practices. Focus on:

- clean naming conventions
- reusable utility patterns
- spacing and rhythm consistency
- color harmony and contrast
- responsive design behavior
- accessibility considerations
- performance and specificity issues
- modern CSS features like flexbox, grid, clamp(), min(), max(), and logical properties

## Output Format

1. Summary of the current styling approach
2. Issues found
3. Recommended refactor
4. Example improved CSS snippets
5. Final suggestions for maintainability and scalability
