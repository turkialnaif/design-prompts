# design-prompts

Comprehensive prompts and instructions for modern web design, UI/UX, CSS, responsive layout, accessibility, motion, and design systems.

## Included prompt sets

- CSS / Styling
- UI/UX Design
- Responsive Design
- Component Design
- Color Theory
- Typography
- Layout & Grid
- Accessibility (A11y)
- Animation & Transitions
- Design Systems

## Use

Use these prompts with ChatGPT, Copilot, or any other AI assistant to generate design feedback, UX recommendations, front-end implementation guidance, and design system improvement suggestions.
