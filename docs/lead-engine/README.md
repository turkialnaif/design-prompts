# محرك العملاء: من موجز المسألة إلى العقد الموقّع

مبني داخل نظام المكتب الحالي (قاعدة البيانات ولوحة الإدارة والبريد)، لا بجانبه. كل موجز يصل من الموقع يمرّ بهذا المسار آليًا، والقرار المهني يبقى للمحامي.

## ما يحدث آليًا
1. **الاستقبال (ثوانٍ):** يُحفظ الموجز في `leads` مع مصدره (utm أو المُحيل وصفحة الدخول)، ويُقيَّم من 100 بقواعد مفسَّرة (`lib/leads/score.ts`): منشأة، بريد منشأة، مفردات ضمن الاختصاص، مبلغ مذكور، استعجال، تفصيل الوصف.
2. **فحص التعارض:** يُقارَن اسم العميل والمنشأة بخصوم الملفات والعملاء الحاليين (`lib/erp/conflicts.ts`) ويظهر التنبيه للمحامي.
3. **ردّ فوري على العميل:** يشرح ما سيحدث وتعهّد الرد خلال يوم عمل، ويقترح قراءتين من أبحاث المكتب تناسبان مسألته ورابط حجز.
4. **تنبيه المكتب:** بريد فيه الدرجة وأسبابها وزرّ واتساب بنص جاهز ورابط الفرصة. (الموجز يصل أيضًا بالبريد القديم؛ يمكن حذفه لاحقًا إن أردت رسالة واحدة.)
5. **متابعات آلية** (مهمة يومية 06:00 UTC): في اليوم 1 و3 و7 و14 لمن لم يُتواصل معه، وتتوقف حين يتواصل أحدكم (`تواصلتُ`)، أو تصبح المرحلة «مؤهَّل» فأبعد، أو يطلب العميل الإيقاف (رابط في كل رسالة، ويحفظ في `suppressions`).
6. **العرض والتوقيع:** من صفحة الفرصة تنشئ عرض أتعاب (نطاق وأتعاب وصلاحية) فيصل العميل برابط `/p/<رمز>`، يقرؤه ويكتب اسمه ويقبل. يُسجَّل الوقت والعنوان والجهاز وبصمة SHA-256 لمحتوى العرض، ثم يُفتح **العميل والملف** تلقائيًا ويصل تأكيد للعميل وتنبيه للمكتب. تذكير واحد بعد 3 أيام إن لم يُحسم.
7. **التنبيهات:** فرص بلا تواصل بعد يوم، وملخص كل أحد (الفرص والعقود والمصادر).

## ما يبقى بيد المحامي
التواصل الأول، وتغيير المرحلة (اجتماع، عرض)، وصياغة العرض والأتعاب، وسبب الخسارة، وأي التزام قانوني. اللوحة: `/admin/leads`.

## التفعيل (مرة واحدة)
1. **ترحيل قاعدة الإنتاج** (جداول جديدة فقط، لا تغيير في الموجود):
   ```bash
   npx vercel env pull .env.production.local --environment=production
   set -a; source .env.production.local; set +a
   npm run db:migrate
   ```
   قبل هذه الخطوة تعمل صفحات الموقع كما هي، لكن لوحة الفرص تعطي خطأً ولا تُحفظ فرص.
2. متغيرات اختيارية في Vercel: `BOOKING_URL` (رابط حجز، وإلا واتساب المكتب)، `LEADS_ALERT_EMAILS` (قائمة مفصولة بفواصل لتنبيه أكثر من شخص)، `NEXT_PUBLIC_SITE_URL`، `ANTHROPIC_API_KEY` (إثراء اختياري بخلاصة من سطرين؛ بدونه لا يُرسل نص الموجز لأي جهة خارجية). `CRON_SECRET` و`RESEND_API_KEY` موجودان.
3. الجدولة: `vercel.json` أضاف `/api/cron/leads` يوميًا (الخطة المجانية تسمح بمهمة يومية فقط، لذلك المتابعات بخطوات يومية).

## المصدر (من أين جاء العميل؟)
أضف وسوم `utm_source/utm_medium/utm_campaign` إلى كل رابط تنشره (لينكدان، إنستقرام، سناب، البريد). يلتقطها الموقع عند أول زيارة ويرفقها بالموجز، فتبيّن لوحة الفرص أي قناة جلبت عقودًا وليس نقرات فقط.

## ما لم يُبنَ عمدًا ولماذا
- **كشط LinkedIn أو قوائم أشخاص ومراسلتهم آليًا:** يخالف شروط المنصة (حظر الحساب)، ويدخل في التسويق المباشر بلا موافقة (نظام حماية البيانات الشخصية)، ويصطدم بضوابط إعلان المحامين واستقطاب العملاء. إن أردت قناة صادرة فالصواب: قائمة أهداف يدوية أو مستوردة بإذن، ومسودات تُرسَل من حسابك أنت بعد قراءتها. يلزم قبلها التحقق من ضوابط الإعلان في نظام المحاماة.
- **حذف الإيقاف وسجل التدقيق وتنبيه التعارض:** هذه حدود نظامية أدنى لا تبطئ شيئًا، وسقوطها يكلّف المكتب أكثر مما يربح.
