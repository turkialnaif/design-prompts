# Instagram grid: nine tiles, one picture

Each file is 1080 x 1440 (3:4, the shape of the profile grid). Together they form `00-the-whole-picture-3240x4320.png`: the firm's mark
drawn at the scale of the grid (two brass lintels, three pillars, a base), the middle pillar in bone.

## Posting order
Post them in the numbered order, 1 to 9. The profile grid shows the newest post first, so tile 9 ("من نحن") ends at the top and tile 1 ("المقر")
at the bottom. Post all nine in one sitting so the picture is complete from the start; add new posts afterwards (they push the picture down one row
at a time, three posts per row, so post in threes if you want to keep it intact).

## Left to right or right to left
The picture is symmetric (three equal pillars, full-width lintels), so it holds together in either direction. On an Arabic-language profile the grid
runs right to left and the text reads in order; on an English-language profile the tiles appear mirrored in order but each is intact.

## Content
Original, not a copy of the website: who we are, the four doors (contracts, companies, arbitration, compliance), five questions before signing,
a rule we work by, how we start, a tip, contact (QR tagged `utm_medium=grid`), and the office. Facts are the site's (hours, address, licence 4477).
